# Edgetx

Some edgeTx related things.

## LuaDemo
Playtn.lua and LuaDemo.yml demostrates how to have a sound generated by the lower half of the Throttle position.   

This lua script needs to be in the SCRIPTS\FUNCTIONS folder on the radio's SD card.  

In this example, Switches SB (3-pos) and SD (2-pos) must **both** be in the down position for the script to be executed.

# OTXSim 
This lua script was tested on the  application and a Radiomaster TX15 ONLY! 

Add this in its own folder under the WIDGETS Folder on the SD or card or the SD folder for the Companion (I used 2.12.5 to test this)

In EdgeTx, select your model, and got to the Edit UI screen.
Add a full screen page, then add this widget onto that.

Exit, and press PageUp or PageDn to view the Widget. 
Tap and hold , select Full Screen.

There are 4 views to choose from.
Wiggle your controls to see the animation on-screen. 

In Full screen view, you can tap Assign to change the visual assignments. 
In my FliteTest SimpleScout, the two Aileron channels are initial rendered to be moving both up or down instead of opposite. Reverse one here to fix such an issue.
**Important** Changes in this Assignment screen does NOT affect your mixes, only the visuals in to screen.Each model's assignments are saved in the OTXSim folder, so it it will persist between sessions.
